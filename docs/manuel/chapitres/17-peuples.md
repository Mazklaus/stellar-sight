Chaque peuple est assemblé à partir de **couches** : un registre (son ton et la manière dont les autres le perçoivent), un archétype (son corps), un gouvernement (sa mécanique propre et son défaut), un credo (son style de recherche) et ses traits. Les fiches qui suivent sont lues dans les données du jeu : elles changeront avec lui.

La difficulté indiquée est une prise en main conseillée, pas un classement : l'équilibre entre peuples sera réglé dans une version plus avancée du jeu.
