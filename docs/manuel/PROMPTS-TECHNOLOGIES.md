# Prompts d'illustration des technologies

Une image par technologie (props 112 et 113 de l'étude de l'arbre de recherche). Le jeu dessine une image de remplacement tant que le fichier `assets/tech/<id>.png` n'existe pas ; déposer l'image sous ce nom suffit.

Format conseillé : carré 1:1, 1024 px, sujet centré (le jeu en tire un médaillon rond pour l'arbre). Brouillon généré depuis les données : sujet par champ, nom et effet de la technologie ; à reprendre en fin de projet.
